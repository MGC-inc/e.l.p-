# 宣言のアクションプラン例（下書き）

- **対象業務**: 週次の「今週の宣言」の登録（bot）。本人の課題（先週いちばん低かった項目）に合わせて、「今週のアクションプラン例」を3つ出す
- **状態**: 今川さん確認済み（2026-11-11。汎用はアポインターが「アポ同行」、「うまくいったトーク」は全項目に添える）。bot に入れた（2026-11-11）。週次パイプラインが weekly-issues/latest.json に人ごとの課題を置き、bot が宣言登録の最初に見せる。「うまくいったトーク」は、その項目がいちばん高い人（名前と率）を示す形で添える
- **使い方（予定）**: 登録を始めると、bot が先に本人の課題を見せる（例「対話→アポ率 20.0%（平均28.1%）」）。続けて下の例から3つを［ボタン］で出し、本人が**例を選ぶか、自分の言葉で決める**。そのあと「いつ」を選んで登録する
- **ボタン名は20字以内**（LINEのボタンの上限）。「詳細」はボタンを押したあとの確認カードに出す
- 例は、このマニュアル（訪問営業.md）の流れ・原則に沿って書いた。実際の数字（誰がどの項目で高いか）から選ぶ「うまくいったトーク」は、別に1つ添える

## 課題の判定

資料（週次MTスライド）の「最優先の改善項目」と同じ判定を使う。先週の通過率が全体平均の90%未満の項目のうち、平均との差がいちばん大きいもの。該当がなければ「伸ばすならここ」の項目。日報が先週1日分もない人は、下の「汎用」から出す。

## アポインター向け

### 訪問→在宅率（インターホンを押しても、在宅に会えない）

| ボタン名 | 詳細 |
|---|---|
| 在宅の多い時間帯に集中 | 先週在宅に会えた時間帯をメモし、今週の訪問の半分以上をその時間に寄せる（毎日） |
| 会えた地区・家に寄せる | 在宅が多かった地区・家のタイプを3つ書き出し、今週はそこから回る |
| 得意な人の回り方に同行 | 在宅率の高い人の訪問に1回同行し、時間帯と順路を聞く（誰と：その人） |

### 在宅→対面率（在宅でも、顔を合わせて話せない）

| ボタン名 | 詳細 |
|---|---|
| 第一声のロープレ3回 | インターホンの第一声を、仲間と3回ロープレする（木・金／誰かと） |
| 第一声を録音して聞く | 自分の第一声を録音して聞き返し、直す点を1つ決める |
| 断られた一言をメモ | インターホンで断られた一言を毎日3つメモし、言い換えを考えて試す |

### 対面→対象率（顔は合わせたが、商談の対象にならない）

| ボタン名 | 詳細 |
|---|---|
| 2名在宅の聞き方を練習 | 「ご夫婦そろってのお時間」の聞き方をロープレ3回（誰かと） |
| 対象外の理由をメモ | 対象外になった理由を毎回メモし、週末に多いものを1つ直す |
| 早めに条件を確認する | 会話の最初の3分で、在宅・主権者の条件を自然に確かめる順番に変える |

### 対象→対話率（対象になっても、話を聞いてもらえない）

| ボタン名 | 詳細 |
|---|---|
| 切り口を言い換える | ハウクリ／メンテの切り口の言い方を2通り決め、交互に試して反応を比べる |
| 最初の30秒を決める | 最初の30秒の話す順番を紙に書いて固定し、毎回その順で話す |
| できる人のトークを聞く | 対話率の高い人の録音（または同行）で、最初の一言を真似して1日試す |

### 対話→アポ率（話は聞いてもらえるが、アポまで進まない）

| ボタン名 | 詳細 |
|---|---|
| 切り返しロープレ3回 | 断られた直後の切り返しを、仲間と3回ロープレする（木・金／誰かと） |
| 日程は2択で聞く | 「木曜と金曜、どちらがよいですか」の2択で日程を聞く形に統一する |
| 録音を聞き返す | 自分のアポ取得の会話を録音して聞き返し、直す点を1つ決める（ひとりで） |

## クローザー向け

### 商談→契約率（自アポ／他アポ）

| ボタン名 | 詳細 |
|---|---|
| 価格提示後の沈黙練習 | 金額提示のあと、自分から話さず待つ練習をロープレ3回 |
| 保証の説明をロープレ | 保証サービスの価値の説明を、仲間にロープレして3回言い直す |
| 録音の転換点を探す | 先週の商談録音を聞き返し、流れが変わった場面を1つ見つけて次に生かす |
| ネック別の返しを作る | 先週の保留・失注のネックを書き出し、それぞれの返しを1つずつ用意する |
| 得意な人の商談に同行 | 契約率の高いクローザーの商談に1回同行し、クロージングを見る |

## 共通（アポインター・クローザー）

| ボタン名 | 詳細 |

| ローンの事前ヒアリング | 銀行ローン契約の場合、審査に関わる点を契約前に聞き取る |

| ボタン名 | 詳細 |

| 稼働開始を前倒しする | 午前の訪問開始を30分早め、移動時間のムダを1か所減らす |
| 回るルートを先に決める | 前日夜に、翌日回るエリアと順路を決めてから出る |

# リーダー会議 業務マニュアル

- **対象業務**: 各代理店のリーダーが集まり、全社の数字と各社の週次MTの結果を共有する会議
- **担当**: 進行＝今川／参加＝各代理店のリーダー（[../従業員.md](../従業員.md) 参照）
- **頻度**: 週次（水曜の週次MTのあと、同じ週のうちに）
- **所要時間目安**: 30分
- **最終更新**: 2026-10-19
- **関連**: 各代理店の週次MTは [週次MT.md](./週次MT.md)

## 1. この業務の目的・完了条件

- 目的: 今川さんが全代理店のMTに出なくても、各社の状況と良いやり方が全社に回る状態にする
- 完了条件: 全代理店の報告がそろい、**全社でやることを1つ**決めて記録した

## 2. 事前準備（各リーダー）

- [ ] 自社の週次MTのスライド①に付けた ◎／○／× の人数を数えておく
- [ ] 自社のMTで紹介した学び・やり方を1つ選んでおく

## 3. 手順（30分）

### 3-1. 全社の数字（5分）

今川さんが、全社MT用PDFと週次MTスライドの全社版（水曜朝8:00に今川さんにだけ届く）で月の進捗と代理店ランキングを確認する。

### 3-2. 各代理店の報告（1社3分。この順番で）

| 順 | 報告すること |
|---|---|
| ① | 先週の数字（月の進捗バーより上か下か、代理店ランキングの順位） |
| ② | 宿題の結果: ◎ が何人、○ が何人、× が何人、記録なしが何人 |
| ③ | チームで一番の課題（一番多くの人の「最優先の改善項目」になっていた項目） |
| ④ | 今週の共有（自社のMTで紹介した学び・やり方を1つ） |

### 3-3. 全社でやることを1つ決める（10分）

- 複数の代理店で③が同じなら、それを全社の課題にする
- ④の中から全社で真似する価値があるものを選び、翌週の全代理店のMT（STEP4の最後）で紹介する
- トークの変更など「やり方そのものを変える」決定は [訪問営業.md](./訪問営業.md) に反映する

### 3-4. 記録

決定事項を `商談分析/YYYY/週次レビュー_YYYY-Wnn.md`（[テンプレ](../商談分析/_週次レビューtemplate.md)）に残す。

## 4. 品質基準・チェックリスト

- [ ] 全代理店が①〜④の形で報告した
- [ ] 全社でやることが1つに決まり、記録された

## 5. よくあるミス・コツ

- 報告が長くなる: 1社3分。①〜④以外は話さない
- × や記録なしが多い代理店を責めない: 原因（MTの時間が取れない、送信をMT中にしていない等）を聞き、週次MT.mdの手順どおりにできているかを確認する

## 6. 困ったときの連絡先

- 一次連絡: 今川

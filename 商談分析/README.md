# 商談分析/ — 週次PDCAレビューの保存先

> 商談録音の**個別分析**はNotion「DB 商談分析＆アポ分析」に蓄積する（[../商談分析運用.md](../商談分析運用.md) 参照）。このフォルダは、そのデータを踏まえた**週次のチームPDCAレビュー**のみを保存する。

## 1. ルール

- **保存場所**: `商談分析/YYYY/`（年ごとのフォルダ）
- **ファイル名**: `週次レビュー_YYYY-Wnn.md`（例: `週次レビュー_2026-W28.md`）
- **テンプレート**: [_週次レビューtemplate.md](./_週次レビューtemplate.md) をコピーして使う
- **コミット形式**: `docs(商談分析): 2026-W28 週次レビュー`
- 個別の商談分析ファイル・録音・文字起こしはここに置かない（Notion・Supabase Storageで管理）

## 2. 個別分析はどこにあるか

- Notion「DB 商談分析＆アポ分析」データベース（クローザー別/アポインター別契約率などのダッシュボード付き）
- 取り込み・分析の仕組みは [.claude/skills/商談録音分析/SKILL.md](../.claude/skills/商談録音分析/SKILL.md)（LINEで録音送信 → Claude Codeに「商談録音を分析して」と指示 → Notion反映）

## 3. Claude Code への指示例

- 「商談録音を分析して」→ Notionに個別分析を反映
- 「今週の商談分析から週次レビューを作って」→ このフォルダに横断集計を作成
- 「〇〇さんの成約率が下がってる原因を過去の分析から探して」→ Notionを検索

# 商談分析/ — 商談録音の分析結果とPDCAの保存先

> 商談録音の分析ファイルと週次レビューを蓄積するフォルダ。運用ルール全体は [../商談分析運用.md](../商談分析運用.md) を参照。

## 1. ルール

- **保存場所**: `商談分析/YYYY/`（年ごとのフォルダ）
- **ファイル名**:
  - 個別分析: `YYYY-MM-DD_担当_顧客.md`（例: `2026-07-11_今川_山田様.md`）
  - 週次レビュー: `週次レビュー_YYYY-Wnn.md`（例: `週次レビュー_2026-W28.md`）
  - 同日に同じ担当・顧客で複数商談があれば `_2` を付けて連番
- **テンプレート**: 個別分析は [_template.md](./_template.md)、週次レビューは [_週次レビューtemplate.md](./_週次レビューtemplate.md) をコピー
- **個別分析の生成**: PLAUD NOTEの録音MP3を `python3 scripts/deal_analysis.py 録音.mp3 --closer 〇〇 --customer 〇〇様` に投げると、このフォルダに分析ファイルが自動生成される（[../商談分析運用.md](../商談分析運用.md) セクション3）
- **コミット形式**: `docs(商談分析): 2026-07-11 今川さん 山田様商談` / `docs(商談分析): 2026-W28 週次レビュー`
- 録音・文字起こし全文はここに置かない（保存先リンクのみ）。顧客の住所・電話番号も書かない

## 2. 通話ログ・議事録との使い分け

| | 商談分析/ | 通話ログ/ | 議事録/ |
|---|---|---|---|
| 対象 | 商談（クロージング）の録音 | 電話のやり取り全般 | MTG（対面・オンライン） |
| 目的 | 営業スキルのPDCA・成約率改善 | 対応漏れ防止・経緯の記録 | 決定事項・TODOの記録 |
| 評価基準 | [マニュアル/訪問営業.md](../マニュアル/訪問営業.md) | — | — |

## 3. Claude Code への指示例

- 「今週の商談分析から週次レビューを作って」
- 「〇〇さんの成約率が下がってる原因を過去の分析から探して」
